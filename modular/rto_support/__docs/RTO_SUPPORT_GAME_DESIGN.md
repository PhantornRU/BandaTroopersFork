# RTO Support: геймдизайн

## 1. Цель роли

`RTO Support` делает RTO отдельной support-ролью с читаемым циклом:

1. выбрать пакет;
2. занять позицию;
3. развернуть сектор, если пакет боевой;
4. вызывать поддержку внутри сектора;
5. управлять общим и личным кулдауном.

Точные числа вынесены в [RTO_SUPPORT_BALANCE.md](RTO_SUPPORT_BALANCE.md). Этот документ фиксирует продуктовые роли пакетов.

## 2. Базовые правила

- Один пресет на жизнь моба.
- Один активный сектор на оператора.
- Поддержка вызывается только через RTO-бинокль.
- `Mortar`, `CAS`, `Heavy Strike` требуют активный сектор.
- `Logistics` сектора не использует.

## 3. Стартовые пресеты

## Mortar

Роль пакета:

- частая утилита;
- одиночные HE, дымовые и зажигательные мины;
- быстрый темп вызовов внутри активного сектора;
- меньший разброс, чем у старой barrage-семантики.

Параметры:

- радиус сектора: `7`
- длительность сектора: `60 секунд`
- кулдаун сектора: `35 секунд`

Способности:

- `HE mortar`: `1` снаряд, scatter `4`, shared `10`, personal `24`
- `Smoke mortar`: `1` снаряд, scatter `3`, shared `8`, personal `18`
- `Incendiary mortar`: `1` снаряд, scatter `4`, shared `14`, personal `32`

Особенность:

- при развёртывании сектора используется illumination payload с фальшфейером;
- сами mortar-вызовы у RTO не повторяют апстримовый barrage и работают как одиночные выстрелы.

## CAS

Роль пакета:

- точечный авиационный удар;
- сопровождение штурма;
- высокая зависимость от открытого неба.

Параметры:

- радиус сектора: `5`
- длительность сектора: `50 секунд`
- кулдаун сектора: `95 секунд`

Способности:

- `Gun run`: scatter `3`, shared `24`, personal `95`
- `Laser run`: scatter `2`, shared `28`, personal `115`
- `Rocket barrage`: scatter `4`, shared `30`, personal `130`

## Heavy Strike

Роль пакета:

- редкий тяжёлый удар;
- высокая цена ошибки;
- короткое окно и длинные кулдауны.

Параметры:

- радиус сектора: `4`
- длительность сектора: `35 секунд`
- кулдаун сектора: `140 секунд`

Способности:

- `Missile strike`: scatter `2`, shared `38`, personal `160`
- `Napalm strike`: scatter `3`, shared `42`, personal `190`

## Logistics

Роль пакета:

- долгий utility support;
- снабжение, мины и турели;
- поддержка "на потом", а не быстрый спам выгодными дропами.

Параметры:

- сектора нет

Способности:

- `Supply drop`: scatter `1`, shared `90`, personal `480`
- `Mine crate drop`: scatter `1`, shared `90`, personal `360`
- `Mini-sentry drop`: scatter `1`, shared `120`, personal `480`
- `Full sentry drop`: scatter `1`, shared `150`, personal `720`

Особенность:

- выгрузка запрещена в закрытые тайлы;
- `Full sentry drop` остаётся самой дорогой логистической кнопкой.
