# RTO Support: памятка игроку

## 1. Коротко

У RTO теперь два типа работы:

- боевые пакеты `Mortar`, `CAS`, `Heavy Strike` работают через сектор наведения;
- `Logistics` работает без сектора и сбрасывает груз напрямую через бинокль.

Во всех случаях наведение идёт через `RTO binoculars`.

## 2. Боевые пакеты: как играть

1. Выберите пакет поддержки.
2. Выйдите на точку с прямой видимостью.
3. Нажмите кнопку сектора наведения.
4. Во время зума через бинокль наведите сектор через `Ctrl+Click`.
5. Пока зона активна, нажмите нужную поддержку.
6. Снова наведите точку через `Ctrl+Click` уже внутри сектора.

Коротко: `выбрал пакет -> поставил сектор -> вооружил кнопку -> навёл через бинокль`.

## 3. Logistics: как играть

1. Выберите `Logistics`.
2. Кнопки сектора у вас не будет.
3. Нажмите нужный сброс.
4. Во время зума через бинокль наведите точку `Ctrl+Click`.

Коротко: `выбрал Logistics -> вооружил сброс -> навёл через бинокль`.

## 4. Utility-режимы бинокля

У RTO есть две отдельные utility-кнопки:

- `Координаты`: даёт координаты и ставит короткую координатную метку.
- `Лазерная отметка`: ставит временную ручную лазерную метку без вызова поддержки.

Если никакой режим не вооружён, `Ctrl+Click` через бинокль всё равно быстро покажет координаты точки.

`Ctrl+Click` по самому биноклю снимает текущее наведение.

## 5. Как читать кнопки

- `Готово`: кнопку можно использовать.
- `Наведение`: кнопка вооружена и ждёт `Ctrl+Click` через бинокль.
- `Активна`: сектор или ручная отметка уже работают.
- `На перезарядке`: идёт кулдаун.
- `Нужен бинокль`: без RTO-бинокля кнопка не работает.
- `Нет сектора`: для боевого пакета сначала нужно развернуть сектор.

На боевых support-кнопках зона отображается отдельно:

- если сектор ещё восстанавливается: `Зона CD: Ns`
- если сектор активен: `Зона: Ns`

## 6. Частые причины отказа

- пакет поддержки ещё не выбран;
- у вас нет `RTO binoculars`;
- вы не смотрите через бинокль во время зума;
- цель вне сектора наведения;
- цель вне прямой видимости;
- цель недоступна по потолку или открытому небу;
- цель на другом уровне;
- выбранный дроп требует открытую площадку;
- способность на общем или личном кулдауне.

Теперь сервер пишет причину в чат, если вызов отклонён.

## 7. Что в каком пакете

- `Mortar`: частая площадная поддержка, дым и выжигание.
- `CAS`: точечная авиация по открытому небу.
- `Heavy Strike`: редкие тяжёлые удары по важным целям.
- `Logistics`: снабжение, ящик с минами, мини-турель и полноценная турель.
